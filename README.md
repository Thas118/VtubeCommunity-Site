# Vtube Community — сайт сообщества

Статический сайт сообщества Vtube Community: услуги монтажа и программирования, калькуляторы стоимости, единая корзина, портфолио и оформление заказа через Telegram.

**Сервер, базы данных, регистрации и Telegram-бота нет** — вся логика работает в браузере, заказ уходит в Telegram готовым сообщением.

## Структура

```text
index.html              — каркас страницы (шапка, вкладки, корзина, модалка, футер)
css/styles.css          — все стили; цвета/градиенты/размеры — в переменных :root
js/utils.js             — форматирование цен, DOM-хелперы, уведомления
js/data.js              — ВСЕ ДАННЫЕ: услуги, цены, портфолио, ссылки, тексты
js/cart.js              — модель единой корзины + localStorage + сообщение заказа
js/calculator.js        — панели отделов и калькуляторы
js/app.js               — вкладки, шторка корзины, карточка клиента, инициализация
assets/                 — фавикон и PNG-заглушка аватара
tests/                  — автотесты (Node.js)
robots.txt              — индексация для поисковиков
```

## Локальный запуск

Любым статическим сервером, например:

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Как редактировать содержимое

Всё содержимое вынесено в **`js/data.js`** — логику трогать не нужно.

| Что менять | Где в `js/data.js` |
|---|---|
| Услуги и цены | `departments[].services[]` (`price` — число в ₽); отделы пока показывают заглушки |
| Новый отдел | запись в `sections[]` + объект в `departments[]` |
| Портфолио (клиенты, работы, ссылки) | `portfolio[]` |
| Текст «Подробнее» | `about` |
| «Наши исполнители» | `team` |
| Нижняя часть (документы) | `footer.blocks` |
| Ссылки (Telegram, Share, сайт) | `links` |

Значения с пометкой `TODO` нужно заменить на финальные: **реальная ссылка Telegram-канала и ссылки клиентов и на работы**.

### Пример: добавить услугу

```js
services: [
  { id: 'voice', name: 'Озвучка', description: 'Текст.', price: 400 }
]
```

Чтобы добавить услугу, внесите объект в массив `services` нужного отдела в `js/data.js`. Пока массив пуст, вместо калькулятора показывается заглушка; как только услуги появятся, откроются калькулятор количества и корзина.

Путь в поле `avatar` можно заменить на файл клиента в формате PNG, JPG или другом поддерживаемом браузером формате изображения. Если файл не загрузится, появится общая PNG-заглушка. Добавляйте выполненные заказы в `works`: число заказов в карточке клиента считается автоматически по количеству работ. Ссылка на YouTube автоматически получает встроенное вертикальное видеопревью; название работы остаётся кликабельной ссылкой.

Для нового отдела добавьте запись в `sections[]` и объект в `departments[]`.

## Как оформляется заказ

1. Пользователь собирает услуги в корзине (единой для всех отделов).
2. Нажимает **«Оформить»**.
3. Сайт формирует сообщение вида:
   ```text
   Хочу оформить заказ в Vtube Community.

   Услуги:
   • Название услуги — количество × цена

   Итого: 2 100 ₽
   ```
   При заполнении полей в корзине в сообщение добавляются имя заказчика,
   контактные данные, данные зрителей и отметка о размещении бота на хостинге исполнителя.
4. Сообщение можно заранее посмотреть в корзине. При оформлении оно копируется в буфер обмена и открывается Telegram Share
   (`https://t.me/share/url?text=...`) — пользователь выбирает чат сообщества.
5. Перед отправкой нужно отметить оба согласия: на обработку персональных данных и с офертой. Без них отправка запрещена.
6. В Telegram остаётся вручную нажать кнопку отправки. Серверно заказ **не** сохраняется, бот **не** используется.

## Как изменить дизайн

Все визуальные параметры — в блоке `:root` файла `css/styles.css`:

- `--accent`, `--accent-2`, `--gradient` — цвета и градиент;
- `--bg`, `--surface`, `--surface-2` — фон и карточки;
- `--radius`, `--gap`, `--pad` — формы и отступы;
- `--container` — ширина контейнера.

Меняя переменные, вы не трогаете разметку и логику.
